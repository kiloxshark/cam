PTZ Commands (Foscam CGI)

The camera uses /decoder_control.cgi?command=N where N is:

  • 0=Up start · 1=Up stop
  • 2=Down start · 3=Down stop
  • 4=Right start · 5=Right stop
  • 6=Left start · 7=Left stop
  • 16=Zoom– · 17=Zoom– stop · 18=Zoom+ · 19=Zoom+ stop
  • 26=H.Patrol start · 27=H.Patrol stop

PTZ Not Working?

Browser CORS blocks fetch() — this viewer uses <img> tags to fire CGI commands which bypasses CORS. Hold buttons for continuous motion. The camera must be on the same network as this page, OR port-forwarded for remote access.
