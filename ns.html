Setup Guide

Step 1 — Find the Camera IP

Connect the camera via Ethernet RJ-45. Open your router admin page and look for a new device. The camera uses DHCP. Note its IP address (e.g. 192.168.1.18) and port (default 88 or sometimes 13900).

Step 2 — Access Web Interface Directly

Open a browser and go to:
http://192.168.1.18:88
Login: admin / no password (or whatever you set). This is the Foscam CGI web UI.

Step 3 — Stream URL

The MJPEG stream URL is:
http://IP:PORT/videostream.cgi?user=admin&pwd=
Snapshot URL:
http://IP:PORT/snapshot.cgi?user=admin&pwd=

Step 4 — Remote Access (Internet)

  • On your router: Port Forward external port 8088 → 192.168.1.18:88
  • Use a free DDNS service (No-IP, DuckDNS) if you don't have a static IP
  • Enter your public IP/DDNS + forwarded port in the "Remote" tab above

Step 5 — PTZ & IR Control

This viewer sends Foscam CGI commands directly to the camera. PTZ, zoom, IR toggle and horizontal patrol all use the /decoder_control.cgi and /set_misc.cgi endpoints.

Browser CORS Note

If the stream shows a CORS error, host this HTML file on the same network as the camera, or use a simple local web server (python3 -m http.server 8080). Alternatively, enable CORS on your router/reverse proxy.
